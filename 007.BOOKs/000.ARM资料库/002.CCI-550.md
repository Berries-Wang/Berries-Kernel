# CCI-550 （Cache Coherent Interconnect ：缓存一致性互联）
ARM CoreLink CCI-550 缓存一致性互连架构:  通过硬件互连总线实现 CPU 集群、GPU、I/O 设备与内存系统之间的全缓存一致性(实现整个 SoC 级别缓存一致性的“总指挥”)。<sub>CCI-550 的核心职责是为 big.LITTLE 架构中的 CPU 集群（如 Cortex-A72/A53）、Mali GPU、视频/显示处理器等提供硬件级缓存一致性</sub>
