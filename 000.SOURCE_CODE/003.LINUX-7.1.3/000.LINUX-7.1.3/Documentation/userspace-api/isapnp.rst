=========================================
ISA Plug & Play support(ISA 即插即用支持)
=========================================

Interface /proc/isapnp(接口 /proc/isapnp)
=========================================

The interface was removed in kernel 2.5.53. See pnp.rst for more details.
(该接口已在内核 2.5.53 中移除。更多细节请参阅 pnp.rst。)

Interface /proc/bus/isapnp(接口 /proc/bus/isapnp)
=================================================

This directory allows access to ISA PnP cards and logical devices.
The regular files contain the contents of ISA PnP registers for
a logical device.
(此目录允许访问 ISA PnP 卡和逻辑设备。常规文件中包含逻辑设备的 ISA PnP 寄存器内容。)
