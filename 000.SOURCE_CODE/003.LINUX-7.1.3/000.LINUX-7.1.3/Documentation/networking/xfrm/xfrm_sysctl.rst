XFRM Syscall(XFRM 系统调用)

/proc/sys/net/core/xfrm_* Variables(/proc/sys/net/core/xfrm_* 变量)

xfrm_acq_expires - INTEGER
(xfrm_acq_expires - INTEGER（整数）)

	(默认值 30 - acquire 请求的硬超时时间（秒）)
