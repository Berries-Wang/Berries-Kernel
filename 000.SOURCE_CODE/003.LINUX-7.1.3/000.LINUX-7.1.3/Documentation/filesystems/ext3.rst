===============
Ext3 Filesystem
===============

(Ext3 文件系统)

Ext3 was originally released in September 1999. Written by Stephen Tweedie
for the 2.2 branch, and ported to 2.4 kernels by Peter Braam, Andreas Dilger,
Andrew Morton, Alexander Viro, Ted Ts'o and Stephen Tweedie.
(Ext3 最初于 1999 年 9 月发布。由 Stephen Tweedie 为 2.2 分支编写，并由 Peter Braam、Andreas Dilger、Andrew Morton、Alexander Viro、Ted Ts'o 和 Stephen Tweedie 移植到 2.4 内核。)

Ext3 is the ext2 filesystem enhanced with journalling capabilities. The
filesystem is a subset of ext4 filesystem so use ext4 driver for accessing
ext3 filesystems.
(Ext3 是增加了日志能力的 ext2 文件系统。该文件系统是 ext4 文件系统的一个子集，因此请使用 ext4 驱动程序访问 ext3 文件系统。)
