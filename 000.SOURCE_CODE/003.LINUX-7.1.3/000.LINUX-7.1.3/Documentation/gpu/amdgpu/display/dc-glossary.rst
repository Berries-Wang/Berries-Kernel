======================
DC Glossary(DC 术语表)
======================

On this page, we try to keep track of acronyms related to the display
component. If you do not find what you are looking for, look at the
'Documentation/gpu/amdgpu/amdgpu-glossary.rst'; if you cannot find it anywhere,
consider asking on the amd-gfx mailing list and update this page.
(本页力图收录与显示组件相关的缩略语。如果找不到你要找的内容，请查看
'Documentation/gpu/amdgpu/amdgpu-glossary.rst'；如果哪儿都找不到，可以考虑在 amd-gfx 邮件列表上提问，并更新本页。)

.. glossary::

    ABM
      Adaptive Backlight Modulation
      (自适应背光调制)

    APU
      Accelerated Processing Unit
      (加速处理单元)

    ASIC
      Application-Specific Integrated Circuit
      (专用集成电路)

    ASSR
      Alternate Scrambler Seed Reset
      (备用扰码器种子复位)

    AZ
      Azalia (HD audio DMA engine)
      (Azalia (高清音频 DMA 引擎))

    BPC
      Bits Per Colour/Component
      (每颜色/分量比特数)

    BPP
      Bits Per Pixel
      (每像素比特数)

    Clocks
      * PCLK: Pixel Clock(像素时钟)
      * SYMCLK: Symbol Clock(符号时钟)
      * SOCCLK: GPU Engine Clock(GPU 引擎时钟)
      * DISPCLK: Display Clock(显示时钟)
      * DPPCLK: DPP Clock(DPP 时钟)
      * DCFCLK: Display Controller Fabric Clock(显示控制器互连时钟)
      * REFCLK: Real Time Reference Clock(实时参考时钟)
      * PPLL: Pixel PLL(像素 PLL)
      * FCLK: Fabric Clock(互连时钟)
      * MCLK: Memory Clock(内存时钟)

    CRC
      Cyclic Redundancy Check
      (循环冗余校验)

    CRTC
      Cathode Ray Tube Controller - commonly called "Controller" - Generates
      raw stream of pixels, clocked at pixel clock
      (阴极射线管控制器——通常称为 "Controller"——生成以像素时钟节拍输出的原始像素流)

    CVT
      Coordinated Video Timings
      (协调视频时序)

    DAL
      Display Abstraction layer
      (显示抽象层)

    DC (Software)
      Display Core
      (显示核心 (软件))

    DC (Hardware)
      Display Controller
      (显示控制器 (硬件))

    DCC
      Delta Colour Compression
      (增量颜色压缩)

    DCE
      Display Controller Engine
      (显示控制器引擎)

    DCHUB
      Display Controller HUB
      (显示控制器集线器)

    ARB
      Arbiter
      (仲裁器)

    VTG
      Vertical Timing Generator
      (垂直时序发生器)

    DCN
      Display Core Next
      (下一代显示核心)

    DCCG
      Display Clock Generator block
      (显示时钟生成器块)

    DDC
      Display Data Channel
      (显示数据通道)

    DIO
      Display IO
      (显示 IO)

    DPP
      Display Pipes and Planes
      (显示管线与平面)

    DSC
      Display Stream Compression (Reduce the amount of bits to represent pixel
      count while at the same pixel clock)
      (显示流压缩 (在相同像素时钟下减少表示像素数量所需的比特数))

    dGPU
      discrete GPU
      (独立 GPU)

    DMIF
      Display Memory Interface
      (显示内存接口)

    DML
      Display Mode Library
      (显示模式库)

    DMCU
      Display Micro-Controller Unit
      (显示微控制器单元)

    DMCUB
      Display Micro-Controller Unit, version B
      (显示微控制器单元，B 版)

    DPCD
      DisplayPort Configuration Data
      (DisplayPort 配置数据)

    DPM(S)
      Display Power Management (Signaling)
      (显示电源管理 (信令))

    DRR
      Dynamic Refresh Rate
      (动态刷新率)

    DWB
      Display Writeback
      (显示回写)

    FB
      Frame Buffer
      (帧缓冲)

    FBC
      Frame Buffer Compression
      (帧缓冲压缩)

    FEC
      Forward Error Correction
      (前向纠错)

    FRL
      Fixed Rate Link
      (固定速率链路)

    GCO
      Graphical Controller Object
      (图形控制器对象)

    GSL
      Global Swap Lock
      (全局交换锁定)

    iGPU
      integrated GPU
      (集成 GPU)

    ISR
      Interrupt Service Request
      (中断服务请求)

    ISV
      Independent Software Vendor
      (独立软件供应商)

    KMD
      Kernel Mode Driver
      (内核态驱动)

    LB
      Line Buffer
      (行缓冲)

    LFC
      Low Framerate Compensation
      (低帧率补偿)

    LTTPR
      Link Training Tunable Phy Repeater
      (链路训练可调 PHY 中继器)

    LUT
      Lookup Table
      (查找表)

    MALL
      Memory Access at Last Level
      (末级内存访问)

    MPC/MPCC
      Multiple pipes and plane combine
      (多管线与平面合并)

    MPO
      Multi Plane Overlay
      (多平面叠加)

    MST
      Multi Stream Transport
      (多流传输)

    NBP State
      Northbridge Power State
      (北桥电源状态)

    NBIO
      North Bridge Input/Output
      (北桥输入/输出)

    ODM
      Output Data Mapping
      (输出数据映射)

    OPM
      Output Protection Manager
      (输出保护管理器)

    OPP
      Output Plane Processor
      (输出平面处理器)

    OPTC
      Output Pipe Timing Combiner
      (输出管线时序组合器)

    OTG
      Output Timing Generator
      (输出时序发生器)

    PCON
      Power Controller
      (电源控制器)

    PGFSM
      Power Gate Finite State Machine
      (电源门控有限状态机)

    PSR
      Panel Self Refresh
      (面板自刷新)

    SCL
      Scaler
      (缩放器)

    SDP
      Scalable Data Port
      (可扩展数据端口)

    SLS
      Single Large Surface
      (单一超大表面)

    SST
      Single Stream Transport
      (单流传输)

    TMDS
      Transition-Minimized Differential Signaling
      (过渡最小化差分信令)

    TTU
      Time to Underflow
      (下溢前时间)

    VRR
      Variable Refresh Rate
      (可变刷新率)
