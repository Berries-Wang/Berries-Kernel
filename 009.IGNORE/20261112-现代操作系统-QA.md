## CSS是什么
- 什么是CSS： https://support.arm.com/documentation/109252/0101/MPAM-System-Guidance-for-Infrastructure/Arm-Neoverse-Compute-Subsystems?lang=en  # Arm Neoverse Compute Subsystems
  - 云计算数据中心、AI 基础设施、高性能计算（HPC）： Neoverse CSS V3 、 Neoverse CSS N3
  - 旗舰智能手机、AI PC、高性能边缘终端： Arm CSS for Client
- https://www.arm.com/zh-cn/products/cloud-datacenter/neoverse-compute-subsystems/css-v3
- Arm Compute Subsystems（计算子系统，简称 CSS）是 Arm 提供的预集成、预验证、经过物理布局优化的完整计算芯片平台，旨在大幅缩短客户设计定制化 SoC 的周期与风险。 与传统仅提供单个 CPU 核心 IP 的模式不同，CSS 将计算核心、缓存、一致性互连总线、系统控制与安全组件打包交付，并针对特定先进制程进行了 PPA（性能、功耗、面积）深度调优
- 「007.BOOKs/learn_the_architecture_introduction_to_amba_chi_c2c_property_negotiation_112071_0100_01_en.pdf」 中的 「Figure 4-2: Arm Neoverse N2 Compute SubSystem (CSS)」
