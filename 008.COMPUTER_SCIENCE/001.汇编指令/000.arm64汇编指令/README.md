# arm64 汇编指令（单指令深潜）

逐条深潜内核/运行库里最常见的 A64 指令：编码、操作伪代码、重定位联动、内核真实用例。

## 目录

| # | 文档 | 指令/原语 | 要点 |
| - | - | - | - |
| 000 | [微指令-SignExtend](./000.微指令-SignExtend.md) | 手册伪代码原语 `SignExtend/Replicate/Zeros` | 不是真实微指令，是 Arm 手册写指令行为用的函数库；`x<M-1>` 取符号位、`:` 拼接 |
| 001 | [ADRP](./001.ADRP.md) | `ADRP Xd, label` | PC 相对取 4KB 页基址；imm21=immhi:immlo（单位是页）；`.o` 里占位 0x90000000+重定位；`0xF0000000` 手算验证 |

## 阅读顺序

先 [000](./000.微指令-SignExtend.md)（伪代码原语，读懂手册的基础）→ 再 [001](./001.ADRP.md)（用原语读懂一条完整指令）。编码总视角见 [../001.机器指令编码&解码](../001.机器指令编码&解码/README.md)。
