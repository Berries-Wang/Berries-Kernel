# 001. 共享内存：唯一的零拷贝通道

> [README](./README.md)｜[000.SysV 公共框架](./000.SysV-IPC公共框架.md)（先读）｜[002.消息队列](./002.消息队列.md)｜[003.Unix管道](./003.Unix管道.md)｜[004.同步型IPC](./004.同步型IPC.md)（配套的同步）｜[005.平台注记](./005.平台注记与调度衔接.md)

SysV shm 的本质是"**内核替你开一个 tmpfs 文件，双方把它 mmap 进地址空间**"：

```c
// ipc/shm.c:704 —— shmget(IPC_PRIVATE/KEY, size, IPC_CREAT)：建对象即建 shmem 文件
static int newseg(struct ipc_namespace *ns, struct ipc_params *params)
{
	...
	sprintf(name, "SYSV%08x", key);   // :742 —— 对象名就是 "SYSV+key"
	...
	file = shmem_kernel_file_setup(name, size, acctflag);  // :766 —— tmpfs 内核变体
	...                                   //（def 链：mm/shmem.c:5868 注释 → :5828 __shmem_file_setup）
}
// ipc/shm.c:662 —— 对象有 file_operations，于是可以走 VFS 的一切（mmap/splice/...）
static const struct file_operations shm_file_operations = { ... };

// ipc/shm.c:1521（do_shmat）→ :1664 —— shmat：把那个文件挂进调用者地址空间
	addr = do_mmap(file, addr, size, prot, flags, 0, 0, &populate, NULL);
```

```
 进程 A 地址空间             物理页 (shmem/tmpfs)            进程 B 地址空间
┌──────────────┐                                             ┌──────────────┐
│ 0x7f…000     │─────┐                                ┌──────│ 0x7f…000     │
└──────────────┘     ▼                                ▼      └──────────────┘
               ┌───────────────────────────────────────────────┐
               │   同一批物理页：A 写入的每一字节，B 立即可见  │
               │   （cache coherent——见 005.平台注记）         │
               └───────────────────────────────────────────────┘
   同步不归 shm 管：得配 futex/信号量/SysV sem（见 004.同步型IPC），否则就是数据竞争
```

- **匿名共享**（无 SysV key）：`mmap(MAP_SHARED|MAP_ANONYMOUS)` → `shmem_zero_setup()`（mm/shmem.c:5929，fork 后父子共享）；`memfd_create()`（mm/memfd.c:505）= 匿名共享 + 有 fd（可跨进程传递、可 seal）；
- **为什么是唯一零拷贝**：消息类通道必须"用户→内核→用户"两次拷贝（内核要排队就要先持有数据，见 [002](./002.消息队列.md)）；共享内存让内核只当"开房东"，数据从头到尾不进内核——代价是同步自理。

## 示例：shmget + shmat 父子传话

```c
/* 001_shm_demo.c: 父子进程经 SysV 共享内存传字符串（零拷贝：同一批物理页） */
#include <stdio.h>
#include <string.h>
#include <sys/ipc.h>
#include <sys/shm.h>
#include <sys/wait.h>
#include <unistd.h>

struct slot { int ready; char data[64]; };

int main(void)
{
	int shmid = shmget(IPC_PRIVATE, sizeof(struct slot), IPC_CREAT | 0600);
	if (shmid < 0) { perror("shmget"); return 1; }

	char *addr = shmat(shmid, NULL, 0);   /* 各自挂进地址空间（do_mmap）*/
	pid_t pid = fork();                   /* fork 后两端指向同一批物理页 */

	if (pid == 0) {                       /* 子进程：读 */
		struct slot *s = (struct slot *)addr;
		while (!s->ready)             /* 教学用自旋；正式代码请用 004 的信号量/futex */
			;
		printf("child read: %s\n", s->data);
		return 0;
	}

	struct slot *s = (struct slot *)addr; /* 父进程：写 */
	strcpy(s->data, "hello via SysV shm");
	s->ready = 1;
	wait(NULL);
	shmdt(addr);
	shmctl(shmid, IPC_RMID, NULL);        /* 引用归零才真正销毁 */
	return 0;
}
```

编译运行（已验证）：

```console
$ gcc -Wall -o 001 001_shm_demo.c && ./001
child read: hello via SysV shm
```
