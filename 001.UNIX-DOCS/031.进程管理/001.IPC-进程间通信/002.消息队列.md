# 002. 消息队列：两次拷贝 + 内核排队（SysV msg / POSIX mqueue）

> [README](./README.md)｜[000.SysV 公共框架](./000.SysV-IPC公共框架.md)（先读）｜[001.共享内存](./001.共享内存.md)｜[003.Unix管道](./003.Unix管道.md)｜[004.同步型IPC](./004.同步型IPC.md)｜[005.平台注记](./005.平台注记与调度衔接.md)

消息通道必须"用户→内核→用户"两次拷贝——内核要排队就得先持有数据。

## 1. SysV msg（ipc/msg.c）

```c
// ipc/msg.c:848（do_msgsnd）—— 发送：拷进内核 + 交接/排队 + 批量唤醒
	msg = load_msg(mtext, msgsz);        // :864（def 在 ipc/msgutil.c:92）—— 第一次拷贝
	...
	/* 队列满：把发送者自己挂上等待队列去睡 —— 011 时机③ 的现场 */
		ss_add(msq, &s, msgsz);          // :907
		schedule();                       // :916 —— 睡到有空间，醒来重试
	...
	if (!pipelined_send(msq, msg, &wake_q)) {   // :939 —— "直通车"：直接交接给正在收的等待者
		/* no one is waiting for this message, enqueue it */
		list_add_tail(&msg->m_list, &msq->q_messages);   // :941 —— 没人等才入队排队
		...
	}
	...
	wake_up_q(&wake_q);                  // :953 —— 批量叫醒（协作 wake_q）
```

接收侧 `do_msgrcv`（ipc/msg.c:1098）对称：按 `msgtyp` 挑一条（或睡等，:1286 `store_msg` 出内核）——**第二次拷贝**完成。队列头对象由 `newque()`（:144）创建，系统调用入口 `msgsnd`（:971）/`msgrcv`（:1270）。

**"直通车"（`pipelined_send`，:816）**：队列只是兜底，**等待者才是首选交接对象**——收方已经在 `do_msgrcv` 里睡等时，发方把消息直接塞给它、连队都不用入。

## 2. POSIX mqueue（ipc/mqueue.c，挂在 `/dev/mqueue` 的迷你文件系统）

- 建：`mqueue_get_inode()`（:289）分配 inode 与队列；
- 发/收：`do_mq_timedsend`（:1037）/ `do_mq_timedreceive`（:1142）；
- **优先级组织**：`msg_insert()`（:190）按 prio 插入 `posix_msg_tree_node`（:60）树——同优先级 FIFO，不同优先级高的先出；
- **直通车双向版**：`pipelined_send`（:1010，发给正在 receive 的等待者）/ `pipelined_receive`（:1019，反向）。协作唤醒用 `wake_q_add_safe()`（:1004，防竞态的批量唤醒队列，见 [010.时钟中断 §4](../008.进程调度/010.时钟中断到调度执行完整路径.md) 的调度衔接）。

## 3. "带类型"：怎么从队列里挑消息

- **SysV `msgtyp` 三段语义**（UAPI 约定，`do_msgrcv` 实现，ipc/msg.c:1098）：`>0` 取第一条该类型的消息；`=0` 纯 FIFO；`<0` 取类型值 ≤ |msgtyp| 中**类型最小**的那条——"带类型的消息传递"就是发送时打 `mtype` 标签、接收时按标签挑选；
- **POSIX mqueue 优先级**：`msg_prio` 落树，接收永远先吐最高优先级；
- 二者的区别是"**标签路由**"（SysV）与"**优先级抢占**"（POSIX）；Protobuf 这类序列化只活在消息**载荷**里，内核不感知（见 [README 总表](./README.md) 备注）。

## 示例：msgsnd/msgrcv 的 msgtyp 挑选语义

```c
/* 002_msg_demo.c: SysV 消息队列——msgtyp 的挑选语义（不带到的先来的，带到的精准取） */
#include <stdio.h>
#include <string.h>
#include <sys/ipc.h>
#include <sys/msg.h>
#include <sys/wait.h>
#include <unistd.h>

struct mymsg { long mtype; char text[32]; };

int main(void)
{
	int msqid = msgget(IPC_PRIVATE, IPC_CREAT | 0600);

	if (fork() == 0) {
		struct mymsg m;
		msgrcv(msqid, &m, sizeof(m.text), 2, 0);   /* msgtyp=2：只收类型 2 */
		printf("child got type %ld: %s\n", m.mtype, m.text);
		return 0;
	}

	struct mymsg a = { 1, "type-1 msg (first)"  };
	struct mymsg b = { 2, "type-2 msg (second)" };
	msgsnd(msqid, &a, strlen(a.text) + 1, 0);  /* 先入队 type 1 */
	msgsnd(msqid, &b, strlen(b.text) + 1, 0);  /* 后入队 type 2 */
	wait(NULL);
	msgctl(msqid, IPC_RMID, NULL);
	return 0;
}
```

编译运行（已验证）——type-1 先入队，`msgtyp=2` 精准取到 type-2：

```console
$ gcc -Wall -o 002 002_msg_demo.c && ./002
child got type 2: type-2 msg (second)
```
