# 003. Unix 管道：内核里的 16 页环形缓冲

> [README](./README.md)｜[001.共享内存](./001.共享内存.md)｜[002.消息队列](./002.消息队列.md)｜[004.同步型IPC](./004.同步型IPC.md)｜[005.平台注记](./005.平台注记与调度衔接.md)

`ls | grep` 的那根竖线 = 一个只有两端 fd 的内核缓冲区：

```c
// include/linux/pipe_fs_i.h
// :5   #define PIPE_DEF_BUFFERS  16        ← 默认 16 个缓冲槽
// :26  struct pipe_buffer {                  ← 一个槽：一页 + 偏移/长度 + 操作表
// :84  struct pipe_inode_info {              ← 整根管道：环形槽数组 + 读/写指针 + 等待队列

// fs/pipe.c:269 / :431 —— 匿名管道的读写实现
anon_pipe_read(struct kiocb *iocb, struct iov_iter *to)   // 消费环形槽
anon_pipe_write(struct kiocb *iocb, struct iov_iter *from)// 灌环形槽，满了睡眠等读端
```

```
   读端 fd[0]                                   写端 fd[1]
      │    ┌───┬───┬───┬───┬───┬───┬───┬───┐         │
      ◄─── │ 0 │ 1 │ 2 │ 3 │ … │ … │   │   │◄────────┘
           └───┴───┴───┴───┴───┴───┴───┴───┘
             16 × pipe_buffer（pipe_fs_i.h:26），每槽一页（PAGE_SIZE，常见 4KB）
             读追 tail（消费最老槽），写追 head（追加到第一个空槽）；空 → 读端睡眠；满 → 写端睡眠
             槽上挂 pipe_buf_operations（anon_pipe_buf_ops，fs/pipe.c:223）
```

- **FIFO（命名管道）**：同一套实现 + 一个 inode 名字（`fifo_pipe_read/write`，fs/pipe.c:406/:603；`fifo_open` :1121 按"另端是否已开"分堵塞/成功分支）——无亲缘进程也能用；
- **fd 继承即共享**：管道没有 ID/名字（区别于 [000](./000.SysV-IPC公共框架.md) 的 key 体系），"共享"靠 fork 继承读写端 fd——`ls | grep` 是 shell fork 两次后各执一端；
- **unix socket**（`unix_stream_sendmsg`，net/unix/af_unix.c:2381）：`socketpair`/AF_UNIX = 可双向、可传 fd（SCM_RIGHTS）的"高级管道"。

## 示例：pipe + fork + dup2 —— `ls | wc -l` 的原型

```c
/* 003_pipe_demo.c: pipe + fork + dup2 —— shell 里 `ls | wc -l` 的原型 */
#include <stdio.h>
#include <sys/wait.h>
#include <unistd.h>

int main(void)
{
	int fd[2];
	pipe(fd);                     /* fd[0] 读端 / fd[1] 写端（内核 16 页环形缓冲）*/

	if (fork() == 0) {            /* 子进程 1：ls，写端接管 stdout */
		dup2(fd[1], STDOUT_FILENO);
		close(fd[0]); close(fd[1]);
		execlp("ls", "ls", (char *)NULL);
		return 1;
	}
	if (fork() == 0) {            /* 子进程 2：wc -l，读端接管 stdin */
		dup2(fd[0], STDIN_FILENO);
		close(fd[0]); close(fd[1]);
		execlp("wc", "wc", "-l", (char *)NULL);
		return 1;
	}
	close(fd[0]); close(fd[1]);   /* 父进程不用两端：关掉，否则 wc 等不到 EOF */
	wait(NULL); wait(NULL);
	return 0;
}
```
