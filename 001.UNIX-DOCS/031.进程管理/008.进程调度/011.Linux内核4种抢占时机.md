# Linux内核4种抢占时机
|抢占时机|说明|备注|
|-|-|-|
|用户态抢占|- 系统调用/中断返回用户态时，检查TIF_NEED_RESCHED -> schedule()|-|
|-|-|-|
|内核态抢占|- 中断返回内核态时，preempt_count==0 且 need_reched -> preempt_schedule_irq() |- 需要CONFIG_PREEMPT=y|
|-|-|-|
|- 显式让出|- 进程调用sched_yield() 或 阻塞在I/O ，锁 ， sleep -> 主动调用schedule()|-|
|-|-|-|
|- 唤醒抢占|- 高优先级任务被唤醒, check_preempt_curr() -> 设置NEED_RESCHED->在最近的抢占点切换|-|
