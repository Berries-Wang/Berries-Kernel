# 内核中特殊的进程
|进程名称|说明|备注|
|-|-|-|
|- 进程0|- 指Linux内核初始化阶段从无到有创建的一个内核线程，是所有进程的祖先。又称 idle进程 或者 swapper进程。 进程0的进程描述符是在init/init_task.c文件中静态初始化的。|- 创建完Init进程后，进程0将会执行cpu_idle函数；当这个CPU上的就绪队列中没有其他可执行的进程时，调度器才会选择执行进程0，并让CPU进入空闲状态. <br/> - SMP 中，每个CPU都有一个进程0|
|-|-|-|
|- 进程1|- Linux内核初始化函数 start_kernel 在初始化完内核所需要的所有数据结构之后会创建另一个内核线程： 进程1(init进程)，进程1的ID为1，与进程0共享进程所有的数据结构|- 会执行kernel_init函数，-> 调用 execve 装入可执行程序init , 最后进程1变成了一个普通进程。<br/> - Init程序: /sbin/init 、/bin/bash、/bin/init|
|-|-|- 进程1从内核线程变为普通进程后，主要的作用： <br/> - 根据/etc/inittab文件启动所需要的任务: 初始化系统配置 、启动一个登录会话|
