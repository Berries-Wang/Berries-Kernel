## 与 5.9 的核心差异(一句话版)
阶段①不再由汇编"一次建好内核映射再开MMU",而是:**先带着空TTBR1开MMU,再由C代码(arch/arm64/kernel/pi/)一次性完成映射/KASLR/重定位** —— 因此 5.9 的 KASLR 回跳环消失,__primary_switched 只进入一次。

## 三个阶段(按执行上下文划分)
<pre>
阶段⓪  建初始ID映射(MMU=off或保持on) │ primary_entry → __pi_create_init_idmap(C代码)
                                     │ → init_kernel_el → __cpu_setup
阶段①  MMU=on, PC=物理地址          │ __primary_switch: 空TTBR1开MMU(走TTBR0初始ID映射)
                                     │ → __pi_early_map_kernel(C)一次性: 映射/KASLR/重定位
                                     │ → br x8(唯一一次跳转, 无回跳!)
阶段②  MMU=on, PC=(可能随机化的)虚拟地址 │ __primary_switched(单次进入) → start_kernel
</pre>

## 图解: KASLR 的两种做法(5.9回跳环 vs 7.1.3直线)
<pre>
5.9(回跳环, 详见 [001.KASLR.md](../../001.KASLR.md)):
  blr试探 → __primary_switched → kaslr_early_init → ret → 关MMU → __create_page_tables
  重建 → 重开MMU → __relocate_kernel → br → 二次进入__primary_switched(跳过KASLR)
  特点: 汇编主导演, __primary_switched可能进入两次, 中间有一个"关MMU窗口"

7.1.3(直线):
  __primary_switch ──bl──▶ early_map_kernel(C) ──ret──▶ br x8 ──▶ __primary_switched(唯一一次)
         │                        │
         │                  ┌─────┴────────────────────────────┐
         │                  │ map_fdt / 清BSS / 特性覆盖         │
         │                  │ kaslr_early_init → kaslr_offset   │
         │                  │   (低21位吸收物理放置偏差,          │
         │                  │    否则2MB块描述符建不出早期映射,    │
         │                  │    map_kernel.c:269-274注释)       │
         │                  │ map_kernel 建VA映射(TTBR1←init_pg_dir)│
         │                  │ relocate_kernel 平移指针(含字面量)   │
         │                  │ 根表复制→swapper_pg_dir(TTBR1切换)  │
         │                  └──────────────────────────────────┘
         └─ 全程MMU开着, PC始终物理地址(走初始ID映射), 没有关MMU的瞬间
  另: 线性映射/模块区的随机化从早期代码移到了 kaslr_init()(kaslr.c:15, setup.c:287调用)
</pre>

## kimage_voffset 的诞生(7.1.3写法)
<pre>
x4 = adrp x4, _text (head.S:233, PC=虚拟地址)      → x4 = VA(_text) = KIMAGE_VADDR + kaslr_offset
x0 = adrp x0, KERNEL_START (head.S:521, PC=物理地址) → x0 = PA(_text)
kimage_voffset = x4 - x0 = VA(_text) - PA(_text)      (head.S:234-235, 只算一次)

随机位移另查: kaslr_offset() = &_text - KIMAGE_VADDR (memory.h:291-294)
例(KASLR关, 加载于0x80200000): 0xffff8000_80000000 - 0x80200000 = 0xffff7fff_ffe00000
(7.1.3源码树无构建产物, 本例为默认配置VA_BITS=48推算值; 5.9实测值见
 [000.KERNEL-5.9文档](./../000.KERNEL-5.9/000.内核启动流程.md))
</pre>
