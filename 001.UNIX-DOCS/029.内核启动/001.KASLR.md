# KASLR（Kernel Address Space Layout Randomization，内核地址空间布局随机化）

## ARM64 KASLR 调用链路分析

ARM64 的 KASLR 实现与 x86 完全不同——它不是在解压缩阶段做的，而是在**内核自引导阶段**，通过在汇编入口与 C 初始化之间来回跳转实现的。

### 调用链全景

```
arch/arm64/kernel/head.S
  │
  ├─ primary_entry()                          # 109行
  │    ├─ preserve_boot_args()                # 保存 FDT 指针
  │    ├─ el2_setup()                         # 降至 EL1
  │    ├─ x23 = __PHYS_OFFSET & (MIN_KIMG_ALIGN-1)  # 113行 — 初始化 KASLR offset=0
  │    ├─ __create_page_tables()              # 创建初始页表（默认虚拟地址）
  │    ├─ __enable_mmu()                      # 开启 MMU
  │    └─ __primary_switch()                  # 跳入
  │
  ├─ __primary_switch()                       # 962行
  │    ├─ __enable_mmu()                      # 968行 — 使能 MMU
  │    ├─ __relocate_kernel()                 # 974行 — 重定位内核
  │    ├─ ldr x8, =__primary_switched         # 976行
  │    └─ blr x8                              # 978行 — 跳入 __primary_switched
  │
  ├─ __primary_switched()                     # 420行
  │    ├─ 设置 VBAR_EL1、SCS、保存 FDT 等
  │    ├─ 清 BSS
  │    ├─ [CONFIG_RANDOMIZE_BASE]
  │    │    ├─ tst x23, ~(MIN_KIMG_ALIGN-1)   # 459行 — 检查是否已随机化
  │    │    ├─ mov x0, x21                    # 461行 — FDT 地址
  │    │    ├─ bl kaslr_early_init()          # 462行 — ★ KASLR 核心
  │    │    ├─ cbz x0, 0f                     # 463行 — 返回0则禁用，跳过
  │    │    ├─ orr x23, x23, x0               # 464行 — 记录 KASLR offset
  │    │    └─ ret                            # 466行 — ★ 回到 __primary_switch()
  │    │
  │    └─ b start_kernel                      # 472行 — 正常路径（无 KASLR）
  │
  └─ [KASLR 二次路径] → __primary_switch()    # 962行（再次进入）
       ├─ 禁用 MMU (msr sctlr_el1, x20)       # 986行
       ├─ __create_page_tables()              # 988行 — ★ 用新偏移重建页表
       ├─ 刷新 TLB + I-cache
       ├─ 重新使能 MMU
       ├─ __relocate_kernel()                 # 999行 — 再次重定位
       └─ br x8 → __primary_switched()        # 1002行
            └─ b start_kernel                 # 最终进入 start_kernel
```

### `kaslr_early_init()` 核心逻辑 (`arch/arm64/kernel/kaslr.c:82-197`)

```
kaslr_early_init(dt_phys)
  │
  ├─ early_fixmap_init()                     # 102行 — 初始化 fixmap
  ├─ fixmap_remap_fdt(dt_phys)               # 103行 — 映射 FDT
  │    └─ 失败 → KASLR_DISABLED_FDT_REMAP, return 0
  │
  ├─ get_kaslr_seed(fdt)                     # 112行 — 从 FDT 读取 kaslr-seed
  │    └─ fdt_path_offset("/chosen")
  │    └─ fdt_getprop("kaslr-seed")
  │    └─ 擦除 seed（*prop = 0）
  │
  ├─ kaslr_get_cmdline(fdt)                  # 118行 — 读取 bootargs
  │    └─ strstr(cmdline, "nokaslr")         # 119行
  │    └─ 匹配 → KASLR_DISABLED_CMDLINE, return 0
  │
  ├─ arch_get_random_seed_long_early(&raw)   # 130行 — 混合硬件随机数
  │    └─ seed ^= raw
  │
  ├─ seed == 0 → KASLR_DISABLED_NO_SEED, return 0
  │
  ├─ 计算 offset:
  │    ├─ mask = ((1 << (VA_BITS_MIN-2)) - 1) & ~(SZ_2M-1)  # 148行
  │    ├─ offset = BIT(VA_BITS_MIN-3) + (seed & mask)        # 149行
  │    │           └─ 将内核放在 VMALLOC 区域的中间一半
  │    └─ memstart_offset_seed = seed >> 48   # 152行 — 随机化线性映射区
  │
  ├─ 计算 module_alloc_base（模块分配基址随机化）
  │    ├─ CONFIG_RANDOMIZE_MODULE_REGION_FULL → 2GB 窗口
  │    └─ 否则 → MODULES_VSIZE 范围内随机
  │
  └─ return offset                           # 196行 — 返回给汇编
```

### ARM64 vs x86 关键差异

| 方面 | x86 (kaslr.c) | ARM64 (kaslr.c + head.S) |
|------|---------------|--------------------------|
| **执行阶段** | 解压缩阶段（`extract_kernel` 内） | 内核自引导阶段（`__primary_switched` 内） |
| **入口函数** | `choose_random_location()` | `kaslr_early_init()` |
| **随机源** | `kaslr_get_random_long()`（RDRAND 等） | FDT 中 `kaslr-seed` + 硬件随机数 |
| **地址空间** | 物理地址 + 虚拟地址分别随机化 | 仅虚拟地址偏移（VMALLOC 区域内） |
| **页表重建** | `add_identity_map()` 按需添加 | 禁用 MMU → 重建全套页表 → 重启用 |
| **重定位** | 解压缩后天然处于新地址 | 通过 `__relocate_kernel()` 显式重定位 |
| **模块随机化** | 无 | 有，`module_alloc_base` 随 KASLR 偏移 |
