# 系统监控 学习资料索引

> 定位:Linux 系统监控 = **内核可观测性机制**(/proc、/sys、ftrace、perf、eBPF、crash)+ **指标解读**(内存 / CPU / I/O / 网络)。本目录现仅有 [000.内存指标项](000.内存指标项.md)(6 行),本索引把仓库里散落的监控资料汇总。只做索引,不改现有笔记。
>
> 页码约定:源码为仓库 Linux 5.9 树的文件;书籍给章节号。
