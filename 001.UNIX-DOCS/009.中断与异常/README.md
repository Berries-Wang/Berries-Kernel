### 中止（Abort）
中止主要有指令中止（instruction abort）和数据中止（data abort）两种，它们通常是指访问外部存储单元时候发生了错误，处理器内部的MMU捕获这些错误并且报告给处理器。

指令中止是指当处理器尝试执行某条指令时发生的错误。而数据中止是指使用加载或者存储指令读写外部存储单元时发生的错误。

---

### 复位（Reset）
复位（reset）操作是优先级最高的一种异常处理。复位操作通常用于让CPU复位引脚产生复位信号，让CPU进入复位状态，并重新启动。

## 如何理解AArch64的异常
![ScreenShot_2026-08-10_232422_513.png](../../001.UNIX-DOCS/999.IMGS/ScreenShot_2026-08-10_232422_513.png)
- 安全世界（Secure World）中的应用主要围绕高敏感数据处理和系统级安全信任根展开，其核心目标是确保即使普通世界（Non-Secure World）被攻破，关键数据和操作仍不可被窃取或篡改。
- 安全世界中典型应用的详细分类与说明：
  + 生物识别与身份认证: 指纹/人脸/虹膜识别处理<sub>摄像头或传感器采集的原始生物特征数据不进入普通操作系统，而是直接送入安全世界的可信应用进行比对和验证:支付宝刷脸支付时，图像数据在安全世界内完成匹配，普通应用仅接收“验证通过”或“失败”的结果</sub>;设备解锁与支付授权<sub>手机锁屏、银行App转账确认等场景，均依赖安全世界内的可信应用完成最终授权，防止恶意软件截获密码或伪造操作</sub>;
  + 数字版权保护
  + 金融与支付安全
    - 移动支付交易签名：微信、支付宝等应用在发起支付时，会将交易数据发送至安全世界，由可信应用使用硬件绑定的私钥进行签名，确保交易不可伪造。
    - 银行卡/信用卡信息存储：部分手机支持将虚拟卡信息存入安全世界，支付时由安全世界直接调用，避免敏感信息暴露在普通系统中。
  + 企业安全与合规
  + 物联网与嵌入式安全
    - 固件更新验签与安全启动：智能门锁、车载ECU等设备在启动或升级固件时，由安全世界验证签名，防止恶意固件注入。
    - 加密通信与密钥协商：IoT设备与云端通信时，TLS握手过程中的私钥运算在安全世界内完成，避免密钥泄露。
  + 区块链与数字资产
  + 系统级安全服务
    - 安全启动链验证：从BootROM到Loader、OP-TEE OS、U-Boot、Kernel，每一级都由安全世界验证签名，构建不可绕过的信任链。
    - 安全监控器调用处理：
      1. SMC 是普通世界请求安全服务的大门 — Normal World 中的操作系统或应用无法直接访问 Secure World 资源，必须先通过 SMC 指令陷入 EL3。
      2. EL3 的 Secure Monitor 负责上下文切换 — 当 SMC 触发时，Secure Monitor 需要：
         - 保存 Normal World 的寄存器状态（通用寄存器、系统寄存器）
         - 恢复 Secure World 的上下文
         - 切换 `SCR_EL3.NS` 位，将 CPU 从 Non-Secure 切换到 Secure 状态
         - 返回时再逆向操作
      3. 权限校验 — Secure Monitor 会验证 SMC 调用的合法性，例如检查 SMC Calling Convention 中定义的 Function ID 是否在允许范围内。
      4. SMC 处理存在两层分发，不是所有 SMC 都由 Secure Monitor 自己处理：
         | SMC 类型 | 处理者 | 说明 |
         |----------|--------|------|
         | Standard SMC（如 PSCI 电源管理） | EL3 Secure Monitor 直接处理 | ARM 体系结构定义的平台协调接口 |
         | Fast SMC（OP-TEE 相关） | 转发到 S-EL1 的 OP-TEE OS | Secure Monitor 只做世界切换，业务逻辑由 OP-TEE 内核中的 SMC 调度器（`thread_smc_handler`）处理 |
         | Yield SMC（OP-TEE 相关） | 同上，但支持抢占式调度 | 允许 OP-TEE 在长时间操作中主动让出 CPU |
      5. 完整的调用链：
         ```
         Normal World App
           → Linux Kernel (NS-EL1)
             → SMC 指令
               → EL3 Secure Monitor (ATF)     ← 上下文切换 + 基础校验
                 → OP-TEE OS (S-EL1)          ← SMC 调度 + 权限+参数验证
                   → Trusted Application (S-EL0) ← 实际业务逻辑
         ```
