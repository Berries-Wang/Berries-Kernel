**短导读（芯片身份一句话 + 结论总览）**：Arm AGI CPU 是 Arm 首款自研量产服务器 CPU——2026-03-24 官方发布、Hot Chips 2026 进一步披露，旗舰 SKU **SP113012** 为 136 核 Neoverse V3、Armv9.2-A、单线程（无 SMT）、12 通道 DDR5-8800、96 条 PCIe Gen6 + CXL 3.0、300 W TDP；Hot Chips 2026 官方演示的媒体转述（Tom's Hardware、ServeTheHome 双源一致）报道其采用**双芯粒**，每芯粒 70 物理核、跨芯粒走 UCIe、聚合带宽 2 TB/s（双向）。11 项核验结论：**9 项含"有依据"成分；需修正集中在六处——"64KB L1"未区分指令/数据缓存、核与网格间省略 CPU bridge + DSU-120、每核独占一个 XP、固定"北向/南向接口"、UCIe 两侧直连 SLC、"UCIe=打包搬运的物理通道"；每芯粒 SLC=64MB、"10 组 D2D"、"熔断"屏蔽、72 XP 等关键数字查不到公开依据，标未确认**——逐项见下文对照表。

**术语与证据级别标注**（全文通用；XP/HN-F 等术语与 [002](002.协议指令集与系统IP分类总览.md)、[003](003.AMBA-CHI-C2C架构-Figure1-3.md) 一致）：

| 标注 | 含义 |
| --- | --- |
| 【官】 | 官方公开资料（产品页/新闻稿/官方文档） |
| 【IP】 | IP 可配置能力（TRM/架构规范），不代表该芯片一定如此实现 |
| 【媒】 | 媒体对官方演示/文档的转述（注明媒体与日期） |
| 【推】 | 由官方数字按双芯粒对半等算术推导 |
| 【未】 | 未确认：查无公开依据或资料冲突 |
| 【家族】 | 由 CMN/DSU 产品家族文档（如 CMN-700）类比该代际，非该型号直接证据 |

标注可组合使用：**点号式【A·B】＝该结论兼具两类证据**（如【官·IP】＝官方公开与 IP 手册双重依据、【媒·双源一致】＝两家媒体转述一致、【IP·家族】＝以家族文档类比的 IP 级能力）；个别行用**冒号式**（如【媒：Tom's】、【官：CMN S3 页 …】、【IP：V3 TRM】）标出单一来源的具体出处；【冲突→未】＝两源冲突、按未确认处理。

- **XP**（Crosspoint，交叉点）：CMN 家族一致性网格的基本路由/交换单元，设备经其 device port 接入网格。
- **HN-F**（Fully Coherent Home Node，全一致归属节点）：管理一段地址空间、通常带 SLC 与 SF 的网格节点。
- **SLC**（System Level Cache，系统级缓存）/ **SF**（Snoop Filter，监听过滤器）/ **PoC/PoS**（Point of Coherency/Serialization，一致点/串行点）。
- **CCG**（CXL Gateway，CXL 网关）：CMN 家族的网关设备，桥接片上 CHI 与 CXS 链路接口——CMN-700 TRM 节点表原文 "CXL Gateway (CCG)"、"A CCG device bridges between CHI and CXS Issue B (SMP or CXL port)"（对侧可为 SMP 对侧芯粒（CML_SMP）或 CXL 端口；每个 CCG 一个 CXS 接口、CMN-700 最多 32 个，[CMN-700 TRM §2.1 节点表 p19](../../007.BOOKs/arm_neoverse_cmn_700_trm_102308_0307_08_en.pdf#page=19)、[§2.5.1 p24](../../007.BOOKs/arm_neoverse_cmn_700_trm_102308_0307_08_en.pdf#page=24)）。跨芯粒 CHI C2C 落到 CMN 互连时即由这类网关承担（CMN S3(AE) 的 D2D 角色：支持 format X、最多 32 个 CCG、支持 CML_SMP，见对照表 #10 与"证据冲突与遗留问题" #6 的可得性说明）。
- **D2D**（die-to-die，裸片间）；**DSU-120**（DynamIQ Shared Unit-120）；**CPU bridge**：V3 核与 DSU-120 之间的桥。
- **CMN-S3 / CMN S3**：同一互连的两种写法——本文正文沿用媒体写法 CMN-S3，Arm 官方产品页与 [002 分类总览](002.协议指令集与系统IP分类总览.md) 用官方写法 CMN S3（出处栏保留官方写法）。
- **AMBA CHI / CHI C2C / UCIe** 三者职责三分见 [003 §6.2](003.AMBA-CHI-C2C架构-Figure1-3.md)；本文直接复用该口径。

**原句逐半判断**：

1. "CMN-S3 一致性网格内部运行的是 AMBA CHI 协议"——**有依据**。CMN S3 官方产品页称其 "native AMBA 5 CHI network"（原生 AMBA 5 CHI 网络）；家族上一代 CMN-700 的 TRM 同样写明 "This chapter introduces CMN‑700 which is an AMBA® 5 CHI interconnect with a customizable mesh topology"（[CMN-700 TRM §2 p17](../../007.BOOKs/arm_neoverse_cmn_700_trm_102308_0307_08_en.pdf#page=17)）。网格上跑 CHI 属于产品与 IP 手册双重印证。
2. "UCIe 则是把这套 AMBA 协议打包搬运到另一颗芯粒的物理高速通道"——**需修正**，三处偏差：
   - **"打包"主体错位**：把消息打包以便跨芯粒传输的是 **AMBA CHI C2C**（Protocol 层做 on-chip CHI ↔ CHI C2C 转换，Packetization 层装入 256B 容器），不是 UCIe。"The AMBA CHI C2C specification focuses on packetization."（[R5 p9](../../007.BOOKs/learn_the_architecture_introduction_to_amba_chi_c2c_property_negotiation_112071_0100_01_en.pdf#page=9)，协议规定）。
   - **"物理高速通道"只覆盖 PHY 一层**：UCIe 自身是多层的互连标准——官方联盟页面写明其规范 "covers the die-to-die I/O physical layer, Die-to-Die protocols, and software stack"（覆盖 D2D 物理层、D2D 协议与软件栈；[UCIe 官网（访问 2026-11-13）](https://www.uciexpress.org/specifications)）；R5 p10 更直接给出链路证据："AMBA CHI C2C can be used over a UCIe Streaming interface, which provides link robustness through **data-link CRC and retry**"——UCIe 的 Data-link 层提供 CRC 与重试，属于链路层功能而非"纯物理"。
   - **中间漏了一层**：在"网格内 CHI"与"UCIe 承载"之间还有 CHI C2C 的完整职责带（转换、打包、流控 credit、初始化与属性协商）。对 CMN S3 家族，这组功能落在网格上的 **CCG 网关设备**（CXL Gateway，桥接 CHI 与 CXS，定义见文首术语表）：官方 CMN S3(AE) 文档列出 CCG 链路支持 format X 的 die-to-die 连接、最多 32 个 CCG 设备、支持 CML_SMP（[CMN S3(AE) TRM 文档页 doc 107858 r0205，访问 2026-11-13](https://support.arm.com/documentation/107858/0205/About-CMN-S3-AE-/Features)；经检索摘要读取，全文核对受页面渲染限制，见"证据冲突与遗留问题"）。R6 §B3.1 Table B3.1 中 Format X 恰好映射 "UCIe 256-byte Latency Optimized Mode"（见 [003 §3.3](003.AMBA-CHI-C2C架构-Figure1-3.md)），与 AGI CPU 媒体报道的 UCIe 承载相互衔接（衔接关系为协议层推断，AGI 内部实现细节未公开）。

**修订表述**：

> CMN-S3 一致性网格内部运行 AMBA CHI 协议；跨芯粒时，由网格上的 CCG 网关经 AMBA CHI C2C 把片上 CHI 消息做协议转换并打包成 256 字节容器，再交给 UCIe 等承载标准，由其数据链路层（CRC、重试等链路功能）与物理层搬运到对侧芯粒。也就是说：打包是 CHI C2C 的职责，UCIe 是承载它的多层互连标准——"物理高速通道"只说对了它的 PHY 层。
