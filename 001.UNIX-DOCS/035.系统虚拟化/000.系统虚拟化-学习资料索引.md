# 系统虚拟化 学习资料索引

> 定位:系统虚拟化 = 在硬件与客户机 OS 之间加一层 VMM/Hypervisor,分别虚拟 **CPU、内存、I/O**(本目录三个子目录正是这三块)。分四层:**教材概念 → ARM64 硬件虚拟化扩展(EL2 / stage 2 / 虚拟中断,重点)→ Linux KVM 实现 → 行业实践**。只做索引,不改现有笔记。
>
> 页码约定:`#page:N` 为 PDF 页码;源码为仓库 Linux 5.9 树的文件。
