# 符号链接和硬链接
|名称|区别|备注|
|-|-|-|
|符号链接(symbolic link)|- 假的文件，只保存目标文件的路径,路径变了，链接也就失效了 <br/> - 相应的inode的数据段包含一个字符串：链接目标的路径|- ![20260204093846.jpg](./999.IMGS/20260204093846.jpg)|
|-|-|-|
|硬链接(hard link)|- 两个目录项，inode编号一样，只是名字不一样 <br/>- 创建的目录项使用了一个现存的inode编号|- ![20260204093758.jpg](./999.IMGS/20260204093758.jpg)|
|-|-|-|
