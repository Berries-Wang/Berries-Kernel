# 地址空间(Address Space)学习资料索引

> 定位:本目录(033.文件系统/008.地址空间)的"地址空间"指 Linux 内核的 **`struct address_space`**——文件 / 页缓存一侧的地址空间抽象(《深入 Linux 内核架构》4.6、16.3)。但"地址空间"一词在不同层次含义不同,本索引按 **概念 → 进程虚拟地址空间 → 文件地址空间(页缓存) → 两者之间的映射(mmap / 反向映射 / 缺页) → 硬件地址空间(页表 / MMU / 物理与 I/O 地址空间)** 分层组织,只做索引不改动现有笔记。
>
> 页码约定:`#page:N` 为 PDF 页码(可直接点开定位);epub 给章节号;源码为仓库内 Linux 5.9 树的文件与行号。
