## 跳转指令

书籍表 1.19 补全（跳转范围由编码里立即数位数决定，这是背表的正确姿势）：

|指令|功能|格式|跳转范围|备注|
|--|--|--|--|--|
|B|无条件跳转|`B label`|PC±128MB（imm26<<2）|—|
|B.cond|条件跳转|`B.EQ label` 等|PC±1MB（imm19<<2）|条件后缀见 [007.条件操作.md](./007.条件操作.md)|
|BL|带链接跳转（调函数）|`BL label`|PC±128MB|返回地址→**X30**|
|BR|跳到寄存器地址|`BR Xn`|任意|间接跳转|
|BLR|带链接跳到寄存器地址|`BLR Xn`|任意|返回地址→X30|
|RET|函数返回|`RET {Xn}`|任意|**默认跳 X30**（省略即 `ret`）|
|CBZ/CBNZ|比较（判零）并跳转|`CBZ Xt, label`|PC±1MB|不置标志，纯判零|
|TBZ/TBNZ|测试位并跳转|`TBZ Rt, #bit, label`|PC±32KB（imm14<<2）|测**单比特**，不置标志|

要点：**跳转范围四档**——`B/BL` ±128MB、`B.cond/CBZ` ±1MB、`TBZ` ±32KB，逐级变小是因为编码位数 26/19/14 位逐级变少。**BR/BLR 是间接跳转**（目标在寄存器，预测器/BTI/侧信道话题都围着它转）。

## 比较指令

|指令|本质|格式|备注|
|--|--|--|--|
|CMP|`SUBS XZR, Xn, Xm` 别名：做减法、丢弃结果、只留标志|`CMP Xn, Xm|#imm`|影响 N/Z/C/V；与 B.cond/CSET/CSEL 配合|
|CMN|`ADDS XZR, …` 别名（负向比较）|`CMN Xn, Xm|#imm`|判"加起来是 0/负"|
|TST|`ANDS XZR, …` 别名|`TST Xn, #imm\|Xm`|按位测试，只看 Z|

书籍的 `cmp x1, x2` 分析（x1+NOT(x2)+1、无符号溢出则 C=1）在 arm64 上有一个**约定级反转**要记住：**A64 的 C=1 表示"无借位"**（与 x86 相反），详见 [007.条件操作.md QA 2](./007.条件操作.md)。

## 内核实例

**① `ret_from_fork`——BL/CBZ/BLR/B 同框**（书籍引用的同一函数，7.1.3 版本）——[arch/arm64/kernel/entry.S:854-863](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/arch/arm64/kernel/entry.S)：

```asm
SYM_CODE_START(ret_from_fork)
	bl	schedule_tail			// BL：调用，返回地址→X30
	cbz	x19, 1f				// CBZ：不是内核线程→跳过
	mov	x0, x20
	blr	x19				// BLR：调线程函数（地址在寄存器）
1:	get_current_task tsk
	mov	x0, sp
	bl	asm_exit_to_user_mode
	b	ret_to_user			// B：尾调用
SYM_CODE_END(ret_from_fork)
```

四条跳转指令各司其职：`bl`（静态已知目标）、`cbz`（判内核线程标志）、`blr`（运行期才知目标的线程入口）、`b`（不回头的尾跳转）。

**② 启动期 TBZ 双端写法**——[arch/arm64/kernel/head.S:141-142](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/arch/arm64/kernel/head.S)：

```asm
CPU_LE( tbnz	x19, #SCTLR_ELx_EE_SHIFT, 1f	)	// 小端构建：EE=1(大端)→跳
CPU_BE( tbz	x19, #SCTLR_ELx_EE_SHIFT, 1f	)	// 大端构建：EE=0(小端)→跳
```

TBZ/TBNZ 的一对变体正好用宏按构建端序二选一。

**③ 编译器实例**（clang 14，`-O2`）——`a < b` 的完整机制：

```asm
unsigned lt_borrow(unsigned long a, unsigned long b) { return a < b; }
	60: cmp   x0, x1		// SUBS XZR：算 a-b 只留标志
	64: cset  w0, lo		// 借位发生（C=0）→ LO → 1
```

## QA

##### 1. BLR 和 `NOP; BR X8` 有什么区别？为什么内核关心？

BLR 会在**跳转前**把返回地址写 X30——语义上"这是函数调用"；BR 是纯转移。安全层面两者都属间接跳转：内核开 BTI（Branch Target Identification）后，`BR/BLR` 的落点必须有 `bti` 垫片或 `paciasp` 等标记，防 JOP 攻击；`ret` 本身不做验证——开启指针认证（FEAT_PAuth，CONFIG_ARM64_PTR_AUTH）的内核在 `ret` 之前用 `autiasp` 验 X30 上的签名。

##### 2. 书籍说 CBZ 跳转范围 ±1MB，为什么是 1MB 不是别的？

imm19 编码，按字节算 2^19×4 = 2MB 总跨度 → 前后各 ±1MB。TBZ 的 imm14 → ±32KB。**背范围不如背编码位数**：`范围 = 2^(位数+2) / 2`。
