> - 编译器示例均为 clang 14 `--target=aarch64-linux-gnu -O2` 实际生成，非手写示意；
> - 机制深潜不在这里展开：原子指令→[../008.同步原语/001.原子指令/](../008.同步原语/001.原子指令/README.md)，内存屏障→[../008.同步原语/002.内存屏障.md](../008.同步原语/002.内存屏障.md)，异常流程→[../009.中断与异常/](../009.中断与异常/)。
