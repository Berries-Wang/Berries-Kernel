# 临界区问题
## 解决临界区问题的三个要求
|要求|说明|备注|
|-|-|-|
|- 互斥访问（mutual exclusion）|- 同一时刻，最多只有一个线程进入临界区|-|
|-|-|-|
|- 空闲让进|- 没有线程在临界区时，必须选一个线程允许其进入临界区|-|
|-|-|-|
|-有限等待|- 当线程申请进入临界区时，必须在有限时间内获得许可|-|

## 解决临界区问题的算法
|算法|说明|备注|
|-|-|-|
|- 关闭硬件中断|- 单核下，线程是按时间片调度的，只要关了中断，就能保证临界区只有一个程序；但在多核下，不能阻塞其它核的线程执行，不能阻止多个CPU核同时进入临界区|- 一个CPU只能控制自己|
|-|-|-|
|- 原子操作|- 软硬结合的方法；无论是CAS还是FAA，需要硬件支持才是真的原子操作|-|
|-|-|-|
|- 互斥锁抽象|- 自旋锁；|- 基本都要使用原子指令实现|
|-|-|-|
