# SK_LOOKUP(BPF_PROG_TYPE_SK_LOOKUP)

> **接管"收包找 socket"这一步**:协议栈按五元组查 listener 之前先问 BPF 程序,程序可以指定 socket——让没有 bind 该端口的进程也能收到流量(透明代理的基础)。枚举值 [bpf.h:1091](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/uapi/linux/bpf.h#L1091);ops 注册 [bpf_types.h:67](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/linux/bpf_types.h#L67);attach type `BPF_SK_LOOKUP` [1134](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/uapi/linux/bpf.h#L1134)。行号 = 仓库 7.1.3 树。

## 1. 使用场景

- **透明代理/sidecar 劫流**:进程不用 bind 80,所有到 80 的连接被程序转给代理 socket(如 Cilium/Tetragon 场景)
- **socket 级服务发现**:按任意策略(不只五元组)选目标 socket
- 作用域是**整个网络命名空间**(netns),不是某个 socket/cgroup

## 2. 上下文与返回值

- 上下文 `struct bpf_sk_lookup *`:protocol/family/local_ip4/remote_ip4/…/cookie,以及 `selected_sk` 输出
- 程序内调 `bpf_sk_assign(ctx, sk, flags)` 指定 socket;返回 `SK_PASS`(接受,可用 assign 的 socket)/ `SK_DROP`(丢)

## 3. 如何生效(attach)

```
方式① BPF_PROG_ATTACH(target = 当前 netns)
  kernel/bpf/syscall.c:4566 分派
    └─ kernel/bpf/net_namespace.c:296 netns_bpf_prog_attach()
         【写入 netns 的 sk_lookup 槽位,同时打开静态键 → 生效】

方式② BPF_LINK_CREATE(推荐,attach_type=BPF_SK_LOOKUP)
  └─ net_namespace.c:420 netns_bpf_link_attach() → link fd
```

## 4. 触发执行路径

```
收包/连接请求查 listener:
  IPv4: net/ipv4/inet_hashtables.c:445 inet_lookup_run_sk_lookup()
          └─ 455 include/linux/filter.h:1709 bpf_sk_lookup_run_v4(prog, …)
  IPv6: net/ipv6/inet6_hashtables.c:212 inet6_lookup_run_sk_lookup()
          └─ 224 include/linux/filter.h:1746 bpf_sk_lookup_run_v6(prog, …)
               └─ bpf_prog_run() → 程序 bpf_sk_assign() 填 selected_sk
                    ├─ 未挂载:静态键关闭,查表路径零开销
                    └─ 挂载后:先跑程序,SK_PASS+assign → 用指定 socket;
                       SK_PASS 无 assign → 正常哈希表查找;SK_DROP → 丢
```

## 5. 如何卸载

- `bpf(BPF_PROG_DETACH)` → [net_namespace.c:382 `netns_bpf_prog_detach()`](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/kernel/bpf/net_namespace.c#L382)(netns 每个 attach 类型只有一个槽位,attach 新程序会替换旧的)
- link 式:close link fd
- netns 销毁时强制清空;prog 引用归零才真正释放(见 [002 §5](002.eBPF生命周期-加载生效卸载.md))
