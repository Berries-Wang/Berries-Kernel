# eBPF 学习资料索引

> 定位:eBPF = **内核内的沙箱虚拟机**——用户态把字节码经 `bpf()` 系统调用交给内核,验证器(verifier)保证安全后 JIT 成本机码,挂到各种钩子(tracepoint / kprobe / TC / XDP / cgroup …)上运行。分四层:**概念与书籍 → 挂载点所依赖的内核机制 → 内核实现源码 → 工具链与外部文档**。本目录 [README](README.md) 已有一份 TC 分类器执行链全景(Aya/Rust 视角),本索引为其补资料面。只做索引,不改现有笔记。
>
> 页码约定:源码为仓库 Linux 5.9 树的文件与行号。
