# PERF_EVENT(BPF_PROG_TYPE_PERF_EVENT)

> **挂在 perf 事件上的程序**:kprobe/tracepoint 也走 perf event 通道,但那些在挂载时按 event 类型分流(见 020/021);`BPF_PROG_TYPE_PERF_EVENT` 专指挂在**纯 perf 事件**(软件事件如 cpu-clock、硬件 PMU 计数溢出、调度器事件)上的程序——perf 溢出中断里执行。枚举值 [bpf.h:1068](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/uapi/linux/bpf.h#L1068);ops 注册 [bpf_types.h:43](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/linux/bpf_types.h#L43)。行号 = 仓库 7.1.3 树。

## 1. 使用场景

- **周期性采样任务**:cpu-clock 软件事件按周期溢出,程序在每次溢出时读上下文(如栈/计数器)写入 map——BCC `profile` 类工具的底层
- PMU 硬件计数器(周期/指令数/cache miss)超阈值时执行自定义逻辑
- 与 020/021 的关系:kprobe:…/tracepoint:… 的 perf event 挂 BPF 时要求 prog type 分别为 KPROBE/TRACEPOINT;`BPF_PROG_TYPE_PERF_EVENT` 只接纯 perf 事件

## 2. 上下文与返回值

- 上下文 `struct bpf_perf_event_data *`(寄存器现场 + perf sample 数据的内核视图,实现 `struct bpf_perf_event_data_kern`)
- 典型 helper:`bpf_perf_event_output()`(往 ring buffer 送样本)、`bpf_get_stackid()`;helper 表 [kernel/trace/bpf_trace.c:1543 `pe_prog_func_proto`](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/kernel/trace/bpf_trace.c#L1543)

## 3. 如何生效(attach)

与 kprobe/tracepoint 同一条 perf 通道:

```
perf_event_open(软件/硬件事件, sample_period=…)
  → perf event fd
bpf(BPF_LINK_CREATE, attach_type=BPF_PERF_EVENT, target_fd=perf_fd)
  └─ kernel/bpf/syscall.c:4191 bpf_perf_link_attach()
       └─ 4222 perf_event_set_bpf_prog()      ← kernel/events/core.c:11704
            └─ 11657 __perf_event_set_bpf_prog() 校验
                 "event 类型 ↔ prog 类型"匹配(必须 PERF_EVENT 型 prog)
            └─ bpf_trace.c:1920 perf_event_attach_bpf_prog()
                 event->prog = prog ──【生效:溢出时被调】
(旧路径 ioctl(PERF_EVENT_IOC_SET_BPF) 同样汇到 11704)
```

## 4. 触发执行路径

```
perf 事件溢出(NMI/软中断上下文):
  kernel/events/core.c perf_event_overflow()
    └─ 10740 判断 event->prog->type == BPF_PROG_TYPE_PERF_EVENT
         └─ core.c:10623 bpf_overflow_handler()
              └─ bpf_prog_run(prog, &perf_data) → JIT 本机码
                   (注意:NMI 上下文 → 程序绝不能睡眠,验证器
                    只允许非 sleepable 的本类型程序)
```

## 5. 如何卸载

```
close(perf event fd) / close(link fd)
  └─ kernel/events/core.c:11718 perf_event_free_bpf_prog()
       └─ kernel/trace/bpf_trace.c:1964 perf_event_detach_bpf_prog()
(引用归零才真正释放,见 002 §5)
```
