# LWT(BPF_PROG_TYPE_LWT_IN / LWT_OUT / LWT_XMIT / LWT_SEG6LOCAL)

> **逐路由的包变换**:lightweight tunnel(lwtunnel)允许把 BPF 程序绑在**一条路由**上——进入路由前(LWT_IN)、路由判定后发出前(LWT_OUT/LWT_XMIT),做封装/解封装/改包。枚举值 [bpf.h:1071-1073](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/uapi/linux/bpf.h#L1071)(IN/OUT/XMIT)、[1080](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/uapi/linux/bpf.h#L1080)(SEG6LOCAL);ops 注册 [bpf_types.h:21/23/25/27](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/linux/bpf_types.h#L21)。行号 = 仓库 7.1.3 树。

## 1. 使用场景

- **自定义隧道**:按路由粒度做封装/解封装(如私有 overlay),不必写内核模块
- **SRv6 编程**:LWT_SEG6LOCAL 挂在 SRv6 segment 行为上
- 与 XDP/TC 的区别:XDP/TC 是**设备**级钩子,LWT 是**路由表项**级——不同前缀可以挂不同程序

## 2. 上下文与返回值

- 上下文 `struct __sk_buff *`(LWT_SEG6LOCAL 为 `struct __sk_buff *` + seg6 相关)
- 返回:`BPF_OK`(0,继续)/ `BPF_DROP`/ `BPF_REDIRECT`(重定向,需 `bpf_redirect()`)/ `BPF_LWT_REROUTE`(IN 程序专用:重新路由)

## 3. 如何生效(attach)

没有独立的 bpf() 挂载命令——**attach 就是把程序写进路由属性**:

```
ip route add 10.0.0.0/24 encap bpf xmit obj prog.o sec xmit dev eth0
  │ (iproute2 内部:加载 prog 后把 fd 放进路由 netlink 属性)
  ▼
lwtunnel 框架按 encap 类型 BPF 匹配:
  net/core/lwt_bpf.c:520 bpf_encap_ops
    ├─ 523 .input  = bpf_input   (LWT_IN)
    ├─ 524 .output = bpf_output  (LWT_OUT)
    └─ 525 .xmit   = bpf_xmit    (LWT_XMIT;7.1.3 由旧名 bpf_lwt_xmit 改名)
  (663 注册 LWTUNNEL_ENCAP_BPF)
  路由对象持有 prog 引用 ──【生效】
```

## 4. 触发执行路径

```
发包命中带 encap bpf 的路由:
  路由查找(dst_input/dst_output)
    ├─ LWT_IN:  bpf_input (lwt_bpf.c:124)  ── 132 run_lwt_bpf()
    ├─ LWT_OUT: bpf_output (lwt_bpf.c:147) ── 155 run_lwt_bpf()
    └─ LWT_XMIT:bpf_xmit   (lwt_bpf.c:276) ── 287 run_lwt_bpf()
                                    │
                                    ▼
                    net/core/lwt_bpf.c:39 run_lwt_bpf()
                      └─ bpf_prog_run() → JIT 本机码
                           OK→继续; REROUTE→重新查路由; REDIRECT→bpf_redirect
```

## 5. 如何卸载

- `ip route replace` 去掉 encap 属性,或 `ip route del` 该路由:路由对象销毁时放掉 prog 引用
- 无独立 detach 命令;prog fd/pin 引用归零才真正释放(见 [002 §5](002.eBPF生命周期-加载生效卸载.md))
