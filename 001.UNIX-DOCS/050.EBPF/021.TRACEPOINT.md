# TRACEPOINT(BPF_PROG_TYPE_TRACEPOINT)

> **内核静态埋点**:`TRACE_EVENT` 宏在内核源码里预留的稳定观测点(如 `sched:sched_switch`、`syscalls:sys_enter_read`),参数格式随内核文档固定,不随函数改名漂移。枚举值 [bpf.h:1066](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/uapi/linux/bpf.h#L1066);ops 注册 [bpf_types.h:41](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/linux/bpf_types.h#L41)。行号 = 仓库 7.1.3 树。

## 1. 使用场景

- 调度器/内存/块 IO/系统调用等**稳定事件**的观测(off-CPU 分析、syscall 审计)
- 事件参数**强类型**:`tracefs` 下每个 tp 有格式文件,libbpf 可自动生成结构体定义(配合 BTF/`vmlinux.h`)
- 工具生态:BCC `tracepoint:sched:sched_switch`、bpftrace `tracepoint:block:*`

## 2. 上下文与返回值

- 上下文是 **tracepoint 参数的线性缓冲区**(`TP_PROTO` 的参数依次排布),按声明的字段偏移读;verifier 会按 tp 的 BTF 校验访问
- 无返回值语义(观测型,数据经 `bpf_perf_event_output()` 送 ring buffer)
- helper 表:[kernel/trace/bpf_trace.c:1439 `tp_prog_func_proto`](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/kernel/trace/bpf_trace.c#L1439)(含 `bpf_perf_event_output_tp`,1372)

## 3. 如何生效(attach)

与 kprobe 共用同一条 **perf event** 通道(7.1.3 中单点挂载的唯一入口是 perf_event_attach_bpf_prog):

```
方式① 旧:perf_event_open(tracepoint:sched:sched_switch)
        + ioctl(PERF_EVENT_IOC_SET_BPF, prog_fd)   ← core.c:6653
方式② 新:bpf(BPF_LINK_CREATE, attach_type=BPF_PERF_EVENT,
             target_fd = perf_fd, prog_fd)
  └─ kernel/bpf/syscall.c:4191 bpf_perf_link_attach()
两条路最终:
  kernel/events/core.c:11657 __perf_event_set_bpf_prog()(校验类型匹配)
    └─ 11704 perf_event_set_bpf_prog()
         └─ kernel/trace/bpf_trace.c:1920 perf_event_attach_bpf_prog()
              └─ prog 塞进 tp_event->prog_array ──【生效】
```

## 4. 触发执行路径

```
代码路径执行到 trace_sched_switch(prev, next) 等埋点宏:
  include/trace/perf.h 模板 perf_trace_##call()
    ├─ 34  bpf_prog_array_valid(event_call)  ← 有 BPF 程序才继续
    └─ 53  perf_trace_run_bpf_submit()
          └─ kernel/events/core.c:11361
               └─ 跑 prog_array 里的程序 + 提交 perf 样本
                    → bpf_prog_run() → JIT 本机码

系统调用专属埋点(不经 TRACE_EVENT 宏):
  入口:kernel/trace/trace_syscalls.c:1375 perf_call_bpf_enter()
         └─ 1393 trace_call_bpf()
  出口:trace_syscalls.c:1516 perf_call_bpf_exit()(1531)
```

## 5. 如何卸载

close perf event fd(或方式②的 link fd):

```
kernel/events/core.c:5828 perf_event_free()
  └─ 11718 perf_event_free_bpf_prog()
       └─ kernel/trace/bpf_trace.c:1964 perf_event_detach_bpf_prog()
            (从 prog_array 移除;引用归零才真正释放,见 002 §5)
```

## 6. 与 raw tracepoint 的区别(选型)

| | TRACEPOINT([本篇](021.TRACEPOINT.md)) | RAW_TRACEPOINT([022](022.RAW_TRACEPOINT.md)) |
|-|-|-|
| 上下文 | 强类型参数缓冲(BTF 校验) | `u64 args[]`,自己转型 |
| 开销 | 稍高(要构造 perf 样本) | 更低 |
| 稳定性 | 跟随 tracefs ABI,稳定 | args 语义随内核变 |

- tp 列表:`cat /sys/kernel/tracing/available_events`;示例 [samples/bpf/syscall_tp_kern.c](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/samples/bpf/syscall_tp_kern.c)
