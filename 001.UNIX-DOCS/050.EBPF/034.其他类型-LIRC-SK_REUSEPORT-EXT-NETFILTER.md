## 3. EXT(BPF_PROG_TYPE_EXT,即 freplace)

- 枚举 [bpf.h:1089](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/uapi/linux/bpf.h#L1089);ops 注册 [bpf_types.h:73](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/linux/bpf_types.h#L73)
- 场景:**替换另一个 BPF 程序的部分指令**(libbpf freplace):加载时 `attach_prog_fd`([bpf.h:1613](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/uapi/linux/bpf.h#L1613))指向目标程序,EXT 程序被"嫁接"进目标的某个全局子函数
- attach:[kernel/bpf/syscall.c:5757-5762 link_create 的 EXT 分支](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/kernel/bpf/syscall.c#L5757)→ 同 [024 的 bpf_tracing_prog_attach](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/kernel/bpf/syscall.c#L3569)(trampoline 机制);卸载:close link fd
- 用途:热补丁一个已部署的 BPF 程序(atomic replacement)

## 4. NETFILTER(BPF_PROG_TYPE_NETFILTER)

- 枚举 [bpf.h:1093](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/uapi/linux/bpf.h#L1093)(较新类型);attach type `BPF_NETFILTER` [1143](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/uapi/linux/bpf.h#L1143);ops 注册 [bpf_types.h:83](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/include/linux/bpf_types.h#L83)

- 上下文 `struct bpf_nf_ctx *`(skb + state);返回 NF_DROP/NF_ACCEPT/NF_STOLEN 等语义
- attach:`BPF_LINK_CREATE`(attach_type=BPF_NETFILTER,指定 hook 点/priority);实现 [net/netfilter/nf_bpf_link.c](../../000.SOURCE_CODE/003.LINUX-7.1.3/000.LINUX-7.1.3/net/netfilter/nf_bpf_link.c)(卸载:close link fd)
