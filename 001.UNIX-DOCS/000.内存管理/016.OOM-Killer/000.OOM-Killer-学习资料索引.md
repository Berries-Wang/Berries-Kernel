> 定位:OOM(Out Of Memory)Killer——内存分配链走到尽头(分配失败 → 直接回收 → `__alloc_pages_slowpath` → `out_of_memory()`)时的"杀进程自救"。分三层:**教材概念(页面置换与负载控制)→ Linux 实现与日志 → 观测与实战**。只做索引,不改现有笔记。
>
> 页码约定:`#page:N` 为 PDF 页码;源码为仓库 Linux 5.9 树的文件与行号。
