# DMA 学习资料索引

> 定位:DMA(Direct Memory Access)——设备不经 CPU 直接读写内存。分四层:**教材原理 → 驱动如何用(DMA API / DMA 引擎)→ 硬件与缓存一致性(ARM64)→ 地址翻译(IOMMU/SMMU)**。它与 [023.MMIO](../023.MMIO%28内存映射IO%29/README.md) 是 CPU↔设备交互的两个方向:MMIO 是 CPU 访问设备,DMA 是设备访问内存。只做索引,不改现有笔记。
>
> 页码约定:`#page:N` 为 PDF 页码;源码为仓库 Linux 5.9 树的文件与行号。

## 4. 地址翻译:DMA 与 IOMMU/SMMU
- 没有 IOMMU 时 DMA 地址 = 物理地址(bounce buffer / 32 位设备限制);有 IOMMU 时设备看到的是 IOVA —— 见 [019.IOMMU 索引](../019.IOMMU/000.IOMMU-学习资料索引.md)、[SMMU Software Guide §4.2](../../../007.BOOKs/learn_the_architecture_-_smmu_software_guide_109242_0100_01_en.pdf#page:25)。
