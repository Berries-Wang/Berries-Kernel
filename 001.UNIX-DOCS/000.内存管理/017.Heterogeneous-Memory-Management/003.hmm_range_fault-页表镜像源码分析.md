# 003. 页表镜像: `hmm_range_fault()` 源码分析 (`mm/hmm.c`)

> 源码: [mm/hmm.c (v6.8, 614 行)](https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/mm/hmm.c?h=v6.8)
> 本文件回答: **GPU 缺页后, 内核如何生成一份"CPU 页表快照"给驱动?**

---

## 1. 实现机制: 一个 mm_walk 页表遍历器

`hmm_range_fault` 本质是一个 `walk_page_range()` (内核通用页表遍历框架) 的用户:

```
                       hmm_range_fault(range)
                              │
                              ▼
              walk_page_range(mm, last, end, &hmm_walk_ops, ...)
                              │
      ┌───────────────────────┼───────────────────┼─────────────────────┐
      ▼                       ▼                   ▼                     ▼
      .test_walk              .pud_entry          .pmd_entry            .pte_hole
      hmm_vma_walk_test       hmm_vma_walk_pud    hmm_vma_walk_pmd      hmm_vma_walk_hole
      跳过 VM_IO/PFNMAP       处理 1G devmap 大页 处理 THP/查 PTE       空洞: 缺页或填0
      的 VMA                                      │
                                                  ▼
                                  hmm_vma_handle_pte() 逐页处理
                                                  │
                                                  ▼
                                  hmm_vma_fault() → handle_mm_fault()
                                  (真正的 CPU 缺页处理!)
```

> 注: `hmm_walk_ops` 还有第 5 个回调 `.hugetlb_entry`(`hmm_vma_walk_hugetlb_entry`, 处理 hugetlb 大页);
> `walk_lock = PGWALK_RDLOCK` 表示整个遍历持 `mmap_read_lock`。两者见上方函数表。

全部函数一览 (v6.8):

| 函数 | 作用 |
|-|-|
| `hmm_pfns_fill` | 把一段页的输出数组统一填成某标志值 |
| `hmm_vma_fault` | 对 `[addr,end)` 逐页调 `handle_mm_fault()` 触发真实缺页, 然后返回 `-EBUSY` 让外层重走 |
| `hmm_pte_need_fault` | **决策核心**: 结合 per-page 请求 + range 默认请求, 判断该页要不要缺页/写缺页 |
| `hmm_range_need_fault` | 对一段页做上述判断的批量版 |
| `hmm_vma_walk_hole` | PTE 空洞回调: 要么缺页要么填 0 |
| `hmm_vma_handle_pmd` | PMD 大页 (THP) 整块快照 |
| `pte_to_hmm_pfn_flags` / `pmd_to_hmm_pfn_flags` | PTE/PMD 权限位 → HMM_PFN_* 翻译 |
| `hmm_vma_handle_pte` | **单页决策核心** (下面逐行讲) |
| `hmm_vma_walk_pmd` / `pud` / `hugetlb_entry` | 各级页表遍历回调 |
| `hmm_vma_walk_test` | VMA 过滤: `VM_IO|VM_PFNMAP` 直接报错或跳过 |
| `hmm_range_fault` | 入口: seqlock 重试循环 |

## 2. 入口: 重试循环

```c
int hmm_range_fault(struct hmm_range *range)
{
	struct hmm_vma_walk hmm_vma_walk = {
		.range = range,
		.last = range->start,
	};
	struct mm_struct *mm = range->notifier->mm;
	int ret;

	mmap_assert_locked(mm);          /* 调用者必须已持有 mmap_read_lock */

	do {
		/* If range is no longer valid force retry. */
		if (mmu_interval_check_retry(range->notifier,
					     range->notifier_seq))
			return -EBUSY;          /* 版本号已过期 → 让驱动重走一遍 */
		ret = walk_page_range(mm, hmm_vma_walk.last, range->end,
				      &hmm_walk_ops, &hmm_vma_walk);
		/*
		 * When -EBUSY is returned the loop restarts with
		 * hmm_vma_walk.last set to an address that has not been stored
		 * in pfns. All entries < last in the pfn array are set to their
		 * output, and all >= are still at their input values.
		 */
	} while (ret == -EBUSY);    /* 关键: -EBUSY = "我刚做了次真缺页, 从头再走" */
	return ret;
}
```

> **为什么缺页后要重走?** `handle_mm_fault()` 会睡眠 (分配内存/等锁), 睡觉期间页表
> 可能被别人改掉, 之前快照的内容不可信 → 从 `hmm_vma_walk.last` 继续, 已填好的前缀
> 不重复填, 没填的后缀重走。这是整个文件最重要的控制流。

## 3. 单页决策核心: `hmm_vma_handle_pte()`

每个 PTE 会落入以下决策树:

```
                    pte = *ptep
                       │
        ┌──────────────┼───────────────────────────┐
        ▼              ▼                           ▼
   pte_none()      !pte_present()             pte_present()
   (还没分配页)     (swap/迁移/设备页等特殊项)      (正常在内存)
        │              │                           │
        ▼         ├─ is_device_private_entry       ▼
   要求缺页?      │    且 owner==自己?              pte 权限满足请求?
   ├─ 是→缺页     │     │ 是→直接报告该 PFN   ├─ 满足 → 填 pfn|VALID
   └─ 否→填 0     │     │ 否→填0或缺页(迁回)  ├─ 否 → handle_mm_fault
                  │                           └─ devmap/zero 按普通页填 PFN; 其余特殊页 → HMM_PFN_ERROR
                  ├─ is_migration_entry ──► migration_entry_wait() 等迁移完成→EBUSY
                  └─ 其他 swap ──► 要求缺页? 缺页: -EFAULT
```

源码 (核心段落, 有删节注释):

```c
static int hmm_vma_handle_pte(struct mm_walk *walk, unsigned long addr,
			      unsigned long end, pmd_t *pmdp, pte_t *ptep,
			      unsigned long *hmm_pfn)
{
	...
	pte_t pte = ptep_get(ptep);
	uint64_t pfn_req_flags = *hmm_pfn;          /* 驱动预先放进数组的"请求" */

	if (pte_none_mostly(pte)) {                 /* 页表项为空 */
		required_fault =
			hmm_pte_need_fault(hmm_vma_walk, pfn_req_flags, 0);
		if (required_fault)
			goto fault;                     /* 驱动要这页 → 真缺页 */
		*hmm_pfn = 0;                           /* 不要 → 报告"没有" */
		return 0;
	}

	if (!pte_present(pte)) {                    /* 特殊 swap entry */
		swp_entry_t entry = pte_to_swp_entry(pte);

		/*
		 * Don't fault in device private pages owned by the caller,
		 * just report the PFN.
		 *  ↑ 关键设计: 页已经在这个 GPU 的显存里, 就直接把 VRAM PFN
		 *    报告给驱动, GPU 继续用, 千万别把页又迁回 DDR!
		 */
		if (is_device_private_entry(entry) &&
		    pfn_swap_entry_to_page(entry)->pgmap->owner ==
		    range->dev_private_owner) {
			cpu_flags = HMM_PFN_VALID;
			if (is_writable_device_private_entry(entry))
				cpu_flags |= HMM_PFN_WRITE;
			*hmm_pfn = swp_offset_pfn(entry) | cpu_flags;
			return 0;
		}
		...
		if (is_migration_entry(entry)) {
			pte_unmap(ptep);
			hmm_vma_walk->last = addr;
			migration_entry_wait(walk->mm, pmdp, addr);  /* 等迁移完 */
			return -EBUSY;                               /* 然后重走 */
		}
		/* Report error for everything else */
		pte_unmap(ptep);
		return -EFAULT;
	}

	cpu_flags = pte_to_hmm_pfn_flags(range, pte);  /* 翻译 CPU 权限位 */
	required_fault =
		hmm_pte_need_fault(hmm_vma_walk, pfn_req_flags, cpu_flags);
	if (required_fault)
		goto fault;                                /* 权限不够 → 写缺页等 */

	/* devmap(DAX)/zero page 旁路检查, 其余特殊页一律报 HMM_PFN_ERROR */
	if (!vm_normal_page(walk->vma, addr, pte) &&
	    !pte_devmap(pte) &&
	    !is_zero_pfn(pte_pfn(pte))) {
		...
		*hmm_pfn = HMM_PFN_ERROR;
		return 0;
	}

	*hmm_pfn = pte_pfn(pte) | cpu_flags;           /* 正常页: 填 PFN+权限 */
	return 0;

fault:
	pte_unmap(ptep);
	/* Fault any virtual address we were asked to fault */
	return hmm_vma_fault(addr, end, required_fault, walk);
}
```

## 4. "要不要缺页"的决策: per-page 请求与 range 默认值的合成

```c
static unsigned int hmm_pte_need_fault(const struct hmm_vma_walk *hmm_vma_walk,
				       unsigned long pfn_req_flags,
				       unsigned long cpu_flags)
{
	struct hmm_range *range = hmm_vma_walk->range;

	/*
	 * So we not only consider the individual per page request we also
	 * consider the default flags requested for the range. The API can
	 * be used 2 ways. ...
	 */
	pfn_req_flags &= range->pfn_flags_mask;   /* mask 关掉的位丢弃 */
	pfn_req_flags |= range->default_flags;    /* 默认值兜底 */

	/* We aren't ask to do anything ... */
	if (!(pfn_req_flags & HMM_PFN_REQ_FAULT))
		return 0;                             /* 根本没要这页 → 不缺页 */

	/* Need to write fault ? */
	if ((pfn_req_flags & HMM_PFN_REQ_WRITE) &&
	    !(cpu_flags & HMM_PFN_WRITE))
		return HMM_NEED_FAULT | HMM_NEED_WRITE_FAULT;

	/* If CPU page table is not valid then we need to fault */
	if (!(cpu_flags & HMM_PFN_VALID))
		return HMM_NEED_FAULT;
	return 0;
}
```

## 5. 真正的缺页: `hmm_vma_fault()`

```c
static int hmm_vma_fault(unsigned long addr, unsigned long end,
			 unsigned int required_fault, struct mm_walk *walk)
{
	...
	unsigned int fault_flags = FAULT_FLAG_REMOTE;

	if (required_fault & HMM_NEED_WRITE_FAULT) {
		if (!(vma->vm_flags & VM_WRITE))
			return -EPERM;                 /* VMA 本身不可写 → 权限错误 */
		fault_flags |= FAULT_FLAG_WRITE;
	}

	for (; addr < end; addr += PAGE_SIZE)
		if (handle_mm_fault(vma, addr, fault_flags, NULL) &
		    VM_FAULT_ERROR)
			return -EFAULT;
	return -EBUSY;     /* ★ 缺页做了, 让上层整个重走一遍保证快照一致 */
}
```

> `FAULT_FLAG_REMOTE`: "替别的进程/设备缺页" 的语义 —— 当前线程不是在访问自己的地址。

## 6. 整体流程图 (驱动视角)

```
 驱动                                mm/hmm.c                     mm/memory.c
  │ mmu_interval_read_begin()              │                             │
  │ mmap_read_lock()                       │                             │
  │ hmm_range_fault(range) ───────────────►│                             │
  │                                        │ walk_page_range()           │
  │                                        │   每个 PTE:                 │
  │                                        │   缺失/权限不够? ──────────►│ handle_mm_fault()
  │                                        │        ◄── 真缺页完成 ───── │ (alloc/读盘/COW)
  │                                        │ return -EBUSY               │
  │ ◄──────────────────────────────────────│  (循环, 从 last 续走)       │
  │ mmap_read_unlock()                     │                             │
  │ lock(update_lock)                      │                             │
  │ mmu_interval_read_retry(seq)? ──是────► 驱动 invalidate 回调改过 GPU 页表? 重来
  │  否                                    │                             │
  │ 用 hmm_pfns[] 写 GPU 页表 (填 GPTE)    │                             │
  │ unlock                                 │                             │
  ▼                                        │                             │
```
