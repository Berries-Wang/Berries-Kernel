## 0. 走读顺序建议

```text
 第一遍(主干):  ① __alloc_frozen_pages_noprof   ← 一切分配的心脏, 先通读
                ② get_page_from_freelist        ← 选 zone 的循环
                ③ rmqueue → __rmqueue_smallest → expand   ← 伙伴系统取块+切割
                ④ __free_one_page               ← 释放合并, 与 expand 对称
 第二遍(补全):  ⑤ __alloc_pages_slowpath        ← 慢路径的"加码"顺序
                ⑥ SLUB 分配链 / 释放链           ← sheaves 新机制
                ⑦ vmalloc / zonelist 构建 / kswapd
```

> 读内核源码的技巧：先看函数开头的注释（如 page_alloc.c:5182 的 *"This is the 'heart' of the zoned buddy allocator"*），再看 `goto` 标签（内核用 `goto` 组织错误处理和重试，如 `retry:`/`nopage:`/`got_pg:`）。
