# IOMMU 学习资料索引

> 定位:IOMMU(Input-Output Memory Management Unit)给**设备发起的访问(DMA)做地址翻译与隔离**——CPU 侧 MMU 管虚拟地址,设备侧由 IOMMU 管;ARM64 上叫 **SMMU**(System MMU)。分四层:**为什么需要 → 通用概念(x86 两大实现)→ ARM64 SMMU(重点)→ Linux 内核实现**。只做索引,不改现有笔记。
>
> 页码约定:`#page:N` 为 PDF 页码;源码为仓库 Linux 5.9 树的文件与行号。

## 1. 为什么需要 IOMMU(概念)

- 解决的问题:①设备只能做 32 位 DMA 时的 bounce buffer;②**隔离**——不设防的设备可 DMA 读写全部物理内存(安全);③虚拟化直通(设备分配给虚机)。
- 教材切入:[现代操作系统 5th §7.7 I/O VIRTUALIZATION #page:526-529](../../../007.BOOKs/现代操作系统/Modern%20Operating%20Systems%205th%20Edition-PDF-01.pdf#page:526) —— IOMMU 是 I/O 虚拟化三种方式(模拟 / 直通 / **SR-IOV**,SR-IOV #page:529)的基础设施;
- 仓库笔记:[023.MMIO/006 §四.4 DMA 方向:SMMU](../023.MMIO%28内存映射IO%29/006.MMIO的缺点-多总线路由与ARM64处理.md) —— 一段话版;[019.IOMMU/README](README.md)(现有 24 行,本索引为其扩充资料面)。
