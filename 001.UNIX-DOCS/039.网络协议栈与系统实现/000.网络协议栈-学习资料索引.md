# 网络协议栈与系统实现 学习资料索引

> 定位:本目录的侧重点是"**系统实现**"——协议栈在内核里怎么跑(收包路径、sk_buff、NAPI/中断、socket 层),以及绕开/加速协议栈的技术(DPDK、RDMA、io_uring、XDP/TC eBPF)。分四层:**用户态 API → 教材概念 → 内核协议栈实现 → 高性能路径**。只做索引,不改现有笔记。
>
> 页码约定:`#page:N` 为 PDF 页码;源码为仓库 Linux 5.9 树的文件与行号。
